    大模型 Langchain 面试题准备¶

    1. langchain包含哪些核心概念?¶

    1.1 langchain 的 components 和 chains 是什么？¶

    详细解答

    Components：模块化的构建块，可以搭积木创建应用程序

    Chains：组合在一起以完成特定任务的一系列Components（或Chains）

    一个chain可能包括一个Prompt模版、一个语言模型一个输出解释器（ICEL链式调用），这些一起工作完成任务

    1.2 langchain 如何 Embedding 和 vector store？¶

    详细解答

    一般常规检索是把数据都先embedding入库，在服务阶段query进来embedding后再快速在库中查询相似topk，然后整合返回给模型。

    1.3 langchain的agents原理？¶

    详细解答

    Agents流程包含下面四个核心步骤：

    1. 接受任务

    2. 思考： 利用LLM进行推理和决策。如可能生成一个潜在的解决方案（如langmanus中的planner node）

    3. 行动：接下来，LLM Agent 会根据任务和思考结果，执行一些操作，比如调用API、访问数据库等

    4. 接收反馈：执行操作后LLM Agent会接收到来自环境的反馈（可能包括API的响应、数据库的查询结果等）

    1.4 langchain如何修改提示模版?¶

    详细解答

    使用from langchain import PromptTemplate，具体实现如下： 

    from langchain import PromptTemplate

prompt = PromptTemplate(
    template=self.config.prompt_template,
    input_variables=["context", "question", "history"]
)

    注意

    在PromptTemplate中，input_variables必须是模版字符串中所有用{}包裹的变量名。

    1.5 langchain如何实现多轮对话?¶

    详细解答

    在langchain中实现多轮对话，需要使用ConversationBufferMemory来存储对话历史：

    from langchain.memory import ConversationBufferMemory

# 创建记忆组件
memory = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=True
)

# 在链中使用记忆组件
conversation = ConversationChain(
    llm=llm,
    memory=memory,
    verbose=True
)

# 进行多轮对话
response1 = conversation.predict(input="你好！")
response2 = conversation.predict(input="我想了解更多关于langchain的信息")

    这样，第二次对话会自动包含第一次对话的上下文。

    1.6 MCP和Function Calling的区别？¶

    详细解答

    Function Calling特点：

    1. 将自然语言转换为可执行的函数调用指令，但是各大厂的实现方式不同

    2. 不同平台实现差异大，切换模型需适配代码

    3. 大模型的插件调用机制

    MCP特点：

    1. 类似USB-C，是开放的通用协议标准

    2. 支持跨平台，模型切换无需重写代码, 一次开发多平台复用

    3. AI于外部工具交互的中间层协议

    4. 敏感数据本地化处理保障安全

    1.7 什么是向量数据库？在大模型应用中主要解决什么问题？¶

    详细解答

    向量数据库： 存储（嵌入）和管理向量数据的数据库，可以将非结构化数据（如文本、图片、音频等）转换为高维向量的形式进行存储，并提供高效的相似性搜索功能。

    例如：Qdrant、Chroma、FAISS、Pinecone

    在大模型应用中主要解决的问题：

    1. 通过将用户查询转为向量，可以快速找到语义相似的topk内容，对于智能文档和推荐系统非常有用。
